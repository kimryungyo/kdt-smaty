# 07. 자동화와 외부 장치

## 목표

Vision, 프로필과 Desk snapshot을 조합해 안전한 목표 높이를 결정하고 WLED 같은
선택 장치를 연결한다.

## 선행 조건

- [대시보드와 프로필](04-dashboard-and-profiles.md) 완료
- [Vision 파이프라인](06-vision-pipeline.md) 완료

## 작업 목록

- [ ] `AutomationService`의 입력·출력 snapshot과 상태를 정의한다.
- [ ] 등록 사용자와 앉음·섬 상태에 따른 프로필 목표 선택을 구현한다.
- [ ] 미등록·불확실·다중 사용자·오래된 Vision에서는 자동 이동을 금지한다.
- [ ] 수동 조절이 자동화보다 우선하고 자동 재개 조건을 명시한다.
- [ ] 같은 목표의 반복 설정을 억제하고 상태 변경 이력을 로그로 남긴다.
- [x] WLED를 선택적 HTTP 어댑터로 구현하고 색상 정책은 자동화 계층에 남긴다.
- [ ] 자동화 시작·중지와 `get_automation()` singleton 접근을 연결한다.

## 테스트

- [ ] 사용자 인식, 자세 전환, 퇴장과 Vision 만료 시나리오를 검증한다.
- [ ] 수동 HOLD·STOP 도중 자동화가 새 목표를 덮어쓰지 않는지 확인한다.
- [ ] 모든 불확실 입력에서 책상이 움직이지 않거나 진행 중 이동을 STOP하는지 검증한다.

## 완료 조건

등록 사용자 시나리오가 자동으로 동작하고, 불확실성·수동 개입·센서 오류에서는
일관되게 안전 정지한다.
