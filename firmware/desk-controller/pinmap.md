# desk-controller 핀 배치 (ESP32-WROOM-32E)

높이 relay와 틸트를 한 보드가 맡는다. 모든 핀은 클래식 ESP32에서 안전한 범용
출력만 쓴다.

## 배선

| 기능 | GPIO | 연결 |
| --- | --- | --- |
| UP 릴레이 | 22 | 릴레이 모듈 IN1 |
| DOWN 릴레이 | 23 | 릴레이 모듈 IN2 |
| 틸트 R_EN | 27 | BTS7960 R_EN |
| 틸트 L_EN | 14 | BTS7960 L_EN |
| 틸트 RPWM | 18 | BTS7960 RPWM |
| 틸트 LPWM | 19 | BTS7960 LPWM |
| GND | GND | 릴레이 모듈·BTS7960 공통 접지 |

릴레이는 active-HIGH다(`RELAY_ACTIVE_LOW = false`). 모듈이 active-LOW면 이 값을
뒤집어야 동작한다.

## 이 핀들을 고른 이유

클래식 ESP32에는 쓰면 안 되는 핀이 여럿이라 아래를 모두 피했다.

| 피한 핀 | 이유 |
| --- | --- |
| 6–11 | 내장 SPI 플래시 전용. 쓰면 부팅하지 못한다 |
| 0, 2, 15 | strapping. 부팅 모드를 바꾼다 |
| 12 | strapping. 부팅 시 HIGH면 플래시 전압이 1.8V로 잡혀 벽돌이 된다 |
| 25, 26 | DAC1/DAC2, RTC 도메인. 부팅 순간 레벨이 확정되지 않는다 |
| 34–39 | 입력 전용. 출력으로 쓸 수 없다 |
| 1, 3 | UART0. 시리얼 진단 로그를 잃는다 |

**25/26을 릴레이에 쓰면 안 되는 이유**는 실물에서 확인했다. 처음 이 두 핀에
배선했을 때 ESP32에 전원을 넣자마자 책상이 올라갔다. 펌웨어의 `begin()`이 OFF를
쓰기 전 수백 ms 동안 핀이 HIGH로 떠 있었고, active-HIGH 릴레이에서는 그것이
그대로 UP 명령이 된다. 22/23은 부팅 내내 하이임피던스라 모듈 풀다운이 OFF를
유지한다.

## 핀을 옮길 때 지켜야 하는 제약

**relay 두 핀과 틸트 enable 두 핀은 반드시 GPIO 0~31이어야 한다.**

최후 안전 정지는 ISR에서 `GPIO.out_w1tc` 레지스터를 직접 쓰는데, 그 레지스터가
GPIO 0~31만 담당한다. 32 이상을 쓰면 비트 마스크가 넘쳐 **차단이 조용히 동작하지
않는다**. `config.h`의 `static_assert`가 빌드에서 이를 막는다.

PWM 두 핀(18, 19)은 LEDC를 거치므로 이 제약을 받지 않는다.

## 하드웨어 타이머

relay는 timer 0, 틸트는 timer 1을 쓴다. 같은 번호를 쓰면 한쪽의 최후 안전 정지가
사라지므로 `config.h`에서 분리해 두었다.
